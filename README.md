# AutoFlex Dashboard — لوحة إدارة البيانات

لوحة تحكم تفاعلية بالعربية (RTL) لعرض وتحليل المصاريف، التوريد، خروج الفواتير، والمرتجعات.
قراءة البيانات من **Google Sheets** عبر **Google Apps Script**، والنشر على **GitHub Pages**.

المطور: **كريم شعير — إدارة البيانات والتحول الرقمي**

---

## 1) تحضير Google Sheet

- تأكد أن ورقة البيانات الرئيسية اسمها `all` (وهي مصدر الحقيقة)، وباقي الأقسام (المصاريف / التوريد / فورم خروج الفواتير) فرعية منها.
- أضِف تبويب فارغ اسمه `المرتجعات` (يحتوي الترويسة فقط) عند بدء تسجيل المرتجعات.

## 2) رفع سكربت Apps Script

1. افتح Google Sheet → **Extensions → Apps Script**.
2. امسح المحتوى الافتراضي والصق محتوى `apps-script/Code.gs` بالكامل.
3. **Deploy → New deployment → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. انسخ رابط Web App الناتج (ينتهي بـ `/exec`).

## 3) ربط اللوحة بالكود

افتح `js/config.js` وضع الرابط في:

```js
API_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

ملاحظة: أول استجابة من رابط Apps Script تحتاج موافقة مرة واحدة (افتح الرابط في متصفح وسمح بالوصول).

> إذا تُرك `API_URL` فارغًا، تعمل اللوحة في **وضع المعاينة** ببيانات تجريبية حقيقية من `data/preview.json` وتظهر رسالة "وضع المعاينة".

## 4) النشر على GitHub Pages

1. ارفع مجلد المشروع كاملًا إلى مستودع GitHub (مجلد جذر المستودع).
2. **Settings → Pages** → Source: **Deploy from a branch** → الفرع `main` والمجلد `/ (root)`.
3. بعد النشر، اللوحة تعمل على `https://<username>.github.io/<repo>/`.

## 5) التحديث التلقائي

- زر **تحديث الآن**: جلب فوري من الجدول (يتجاوز الكاش).
- قائمة **تحديث تلقائي**: إيقاف / 1 / 5 / 15 / 30 دقيقة.
- الفلاتر والتقارير تعمل محليًا على نسخة محمّلة من البيانات في الذاكرة (بدون تحميل متكرر).

## 6) إضافة بيانات أو أقسام جديدة

- أي صف يُضاف لتبويب `all` في الشيت يظهر تلقائيًا عند التحديث.
- لإضافة جدول/قسم جديد: أضف التعريف في `ALL_SCHEMA` و`APP_SECTIONS` داخل `js/config.js`.

## هيكل المشروع

```
├── index.html              الواجهة
├── css/style.css           التصميم
├── js/
│   ├── config.js           الإعدادات + مخطط الأعمدة
│   ├── utils.js            أدوات (تواريخ، عملة، تحليل خصم...)
│   ├── api.js              جلب البيانات من Apps Script
│   ├── data.js             تطبيع البيانات + فلاتر + مؤشرات
│   ├── filters.js          قوائم الفلاتر
│   ├── charts.js           الرسوم البيانية (Chart.js)
│   ├── tables.js           الجداول التفاعلية (بحث/ترتيب/ترقيم)
│   └── app.js              المحرّك الرئيسي
├── apps-script/Code.gs     API الخاص بـ Google Sheets
└── data/preview.json       نسخة معاينة محلية (احتياطي)
```

## ملاحظات جودة البيانات

- مشاكل البيانات المعروفة موثقة في `DATA_ISSUES.md` (عمود 19 بدون اسم، تنسيقات تاريخ وصور، اختلافات أسماء المحافظات...).
- قسم **جودة البيانات** داخل اللوحة يعرض المشاكل دون تعديل الأصل.
